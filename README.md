1. Unzip the file, find MiniaTermExtension
2. Open up Google Chrome
3. Click on the puzzle piece sign near the top of the screen
4. Click on Manage Extensions on the bottom of the dropdown menu
5. Click on Load Unpacked
6. Select the MiniaTermExension file, and click open.
7. The extension is now installed, and will work passively whenever it detects a terms and conditions page.

Note: This application uses Google Gemini API, you need to use your own gemini API key for it to work, please replace the old API key thats in background.js with your own.
